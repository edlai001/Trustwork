# TrustWork – freelance escrow on Ethereum

A client locks ETH in a smart contract when posting a job. A freelancer accepts it,
submits the work, and is paid automatically when the client approves.

**Live site:** https://edlai001.github.io/Trustwork/ (Sepolia testnet)  
**Contract:** [0xe98610A9825518D9E3144A48f36d83B29F8eD97f](https://sepolia.etherscan.io/address/0xe98610A9825518D9E3144A48f36d83B29F8eD97f)

## Project layout
| Path | What it is |
|---|---|
| `contracts/TrustWork.sol` | The smart contract |
| `test/TrustWork.test.js` | 9 automated tests |
| `frontend/index.html` | The app (post / accept / submit / approve / cancel jobs) |
| `frontend/deploy.html` | Deploy the contract to Sepolia from MetaMask (no private key in files) |
| `frontend/config.js` | Contract address + network settings |
| `frontend/contract.js` | ABI + bytecode, generated by `npm run export` |
| `.github/workflows/pages.yml` | Publishes `frontend/` to GitHub Pages |

## Commands
```
npm install
npm test          # run the tests
npm run export    # compile and copy ABI/bytecode into frontend/contract.js
```

## Deploying to Sepolia
1. Get free Sepolia ETH (see below).
2. Open `deploy.html` on the live site, connect MetaMask, click **Deploy**, confirm in MetaMask.
3. Copy the address into `contractAddress` in `frontend/config.js`, commit and push.

## Running locally (optional)
`npx hardhat node`, then `npx hardhat run scripts/deploy.js --network localhost`.
In `frontend/config.js` set `chainId: "0x7a69"`, `rpcUrls: ["http://127.0.0.1:8545"]`
and the printed address, then open `frontend/index.html`.

No private keys or secrets are stored anywhere in this repository.
